# CDR Banking & Energy Test Data -- Master Schema Catalog

## Purpose

This document describes all 18 entity types in the Australian Consumer Data Right (CDR) test data set generated by `testdata-cli`. It serves as a quick reference for developers building against CDR APIs, testers validating data holder implementations, and AI agents that need to understand the data shape.

**CDR Standards Version:** 1.33.0
**Generated:** 2026-07-16
**Source:** `output/combined.json`, `output/banking.json`, `output/energy.json`, `output/customers.json`

## Data Quality Notes

### ID Patterns
- **Account/product/payee IDs:** UUID v4 format (e.g., `18be7477-ffaa-4c2d-94fb-e689650e0502`)
- **NMI (National Metering Identifier):** 11-digit string (e.g., `62668332710`)
- **Invoice numbers:** Numeric strings (e.g., `962519712`)
- **Account numbers:** 8-digit strings (e.g., `77633857`)
- **BSB:** 6 digits with hyphen (e.g., `175-036`)

### Date/Time Formats
- All timestamps use ISO 8601 with timezone: `2026-07-01T14:12:50.821Z`
- Duration fields use ISO 8601 Durations: `P1M`, `P3Y6M4DT12H30M5S`
- Tariff period dates may use `mm-dd` format within schemas

### Currency & Amount Representation
- Monetary amounts are **strings** formatted as decimals: `"1234.56"`, `"-70122.69"`
- Negative amounts indicate money owing (balances) or outgoing (transactions)
- Currency codes follow ISO 4217; `AUD` is assumed if absent
- Rate values are string decimals: `"0.04"` for 4%

### Address Formats
- PAF (Postal Address File) format follows Australia Post specifications
- State values: `NSW`, `QLD`, `VIC`, `NT`, `WA`, `SA`, `TAS`, `ACT`, `AAT`
- Country codes: ISO 3166 Alpha-3 (default `AUS`)

### Enum Conventions
- All enum values are UPPER_SNAKE_CASE
- Absent optional enum fields have documented default values (e.g., `openStatus` defaults to `OPEN`)

## Data Hierarchy

```

├── holders[]
│   └── holder
│       ├── unauthenticated

│       └── authenticated.customers[]
│           ├── customer

│           ├── banking
│           │   ├── accounts[]
│           │   │   ├── account                 → BankingAccount
│           │   │   ├── balance                 → BankingBalance

│           │   ├── directDebits[]              → BankingDirectDebit
│           │   ├── payees[]                    → BankingPayee
│           │   └── payments[]                  → BankingScheduledPayment
│           └── energy
│               ├── accounts[]
│               │   ├── account                 → EnergyAccount
│               │   ├── invoices[]              → EnergyInvoice
```

## How to Regenerate

```bash
cd testdata-cli

# Install dependencies
npm install

# Generate test data (writes to output/)
npm run build && npm run generate

# The generated files:
# output/combined.json   — full nested dataset
# output/customers.json  — 200 customers
# output/banking.json    — banking subset
# output/energy.json     — energy subset
```

Refer to `src/schema/cdr-test-data-schema.ts` for the complete TypeScript type definitions.
